# Dataset Documentation

## Data Source
- **Dataset:** Telco Customer Churn
- **Author / Publisher:** `blastchar` (originally sourced from IBM Sample Data Sets)
- **Platform:** Kaggle (`blastchar/telco-customer-churn`)
- **Filename:** `WA_Fn-UseC_-Telco-Customer-Churn.csv`
- **Description:** Contains 7,043 telecom customer records with 21 attributes covering customer demographics, account information, subscribed services, and the target `Churn` label.

## Directory Structure
- `data/raw/` — Stores the unmodified source CSV file (`WA_Fn-UseC_-Telco-Customer-Churn.csv`). Ignored by Git.
- `data/processed/` — Stores cleaned datasets and engineered features generated by preprocessing scripts. Ignored by Git.
